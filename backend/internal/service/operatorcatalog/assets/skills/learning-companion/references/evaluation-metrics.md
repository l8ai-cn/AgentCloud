# Evaluation Metrics

Use 0-100 integer values. Prefer conservative updates.

| Metric | Meaning |
| --- | --- |
| knowledgeMastery | Average mastery of active knowledge nodes |
| reviewPressure | Urgency of spaced review |
| misconceptionRisk | Risk from repeated wrong ideas |
| learningInitiative | Student-initiated questions, notes, and attempts |
| transferAbility | Applying concepts in new tasks/code |
| persistence | Retry and correction behavior |
| resourceGrounding | Use of course/wiki evidence |

Metrics should explain growth, not rank students.
