# Student Profile Schema

Recommended `evaluation/profile.json` shape:

```json
{
  "studentId": "",
  "courseId": "",
  "updatedAt": "",
  "summary": "",
  "strengths": [],
  "weaknesses": [],
  "preferredLearningMode": "practice_first",
  "recentFocusNodes": [],
  "recommendedNextActions": []
}
```

Keep the profile short. Store evidence in `raw/`, detailed explanations in `wiki/`, and numeric signals in `evaluation/metrics.json`.
