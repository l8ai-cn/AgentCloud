# Pattern Seam Review

Use this skill to verify whether a textile repeat unit tiles cleanly.

## Contract

- Check opposite edges, offset previews, and at least one tiled preview.
- Report visible seams, motif cuts, scale discontinuity, and color jumps.
- Distinguish aesthetic concerns from production blockers.
- Provide concrete fix instructions when the repeat fails.
- Do not approve without evidence from generated previews or deterministic inspection.

## Output

Return pass/fail status, evidence files, risks, and required fixes.
