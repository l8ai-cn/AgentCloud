# Course Practice Builder

Use this skill to create practice questions, quizzes, and assessment rubrics.

## Contract

- Align every question with a specific learning objective.
- Mix recall, application, diagnosis, and synthesis tasks when appropriate.
- Provide answer keys, scoring rules, and feedback guidance.
- Avoid ambiguous questions and unverifiable subjective grading.
- Mark questions that require teacher review.

## Output

Return the practice set, answer key, rubric, and review notes.
