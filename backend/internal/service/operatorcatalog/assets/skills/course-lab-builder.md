# Course Lab Builder

Use this skill to design practical labs and hands-on course activities.

## Contract

- Define setup, steps, expected outputs, checks, and troubleshooting notes.
- Make each lab executable by the target learner with available tools.
- Separate optional extensions from required completion criteria.
- Include grading or inspection evidence for each checkpoint.
- Flag any external dependency, dataset, credential, or environment risk.

## Output

Return the lab runbook, checkpoint table, submission requirements, and validation plan.
