# Pattern Generate

Use this skill when a textile pattern partner needs to create, refine, or regenerate motif assets from references.

## Contract

- Start from the supplied image, motif description, palette, target product, and repeat constraints.
- Preserve visible structure and design intent unless the user asks for a variant.
- Record source assumptions, prompt decisions, and generated asset names.
- Separate motif generation from repeat-canvas composition.
- Do not claim a pattern is seamless until `pattern-seam-review` has checked it.

## Output

Return the generated asset plan, prompt set, file list, and review notes.
