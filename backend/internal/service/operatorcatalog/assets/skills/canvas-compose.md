# Canvas Compose

Use this skill to arrange textile motifs into a repeatable production canvas.

## Contract

- Choose a repeat strategy: grid, half-drop, brick, tossed, border, or custom placement.
- Keep motif scale, spacing, direction, and density explicit.
- Produce a canvas plan before final layout.
- Preserve enough margin and overlap information for seam review.
- Flag production risks such as oversized focal motifs, crowded spacing, or weak contrast.

## Output

Return the repeat strategy, layout parameters, generated canvas files, and handoff notes for seam review.
