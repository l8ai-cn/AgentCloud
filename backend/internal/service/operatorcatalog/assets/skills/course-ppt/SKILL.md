# Course PPT

Write slide planning artifacts under
`output/projects/<project-id>/artifacts/slides/`.

Required files:

- `course-ppt-brief.md`
- `slide-outline.md`
- `slide-cards.md`
- `speaker-notes.md`
- `asset-list.md`
- `quality-audit.md`

Each slide card contains page type, teaching intent, title, student-visible content,
teacher explanation, interaction, visual need, and a check or evidence point. Slides
must teach one concrete mechanism or action, not decorate a list of job functions.

For technical lessons, include minimal syntax, input/output, decision rule, or
observable operation. Never fabricate screenshots, metrics, notebook output, or
platform state.

This skill can always produce a verified slide plan. A final PPT/PDF/video requires a
mounted visual production capability and actual rendered-file inspection. If that
capability is absent, mark final rendering blocked; do not call the plan a PPT file.
