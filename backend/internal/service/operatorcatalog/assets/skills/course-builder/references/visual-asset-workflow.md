# 课程配图与图示生成流程

用于课程页面需要视觉辅助时。目标是降低理解成本，不是装饰页面。

## 1. 是否需要配图

先判断教学内容类型：

| 内容类型 | 是否建议配图 | 图示类型 |
| --- | --- | --- |
| 流程步骤超过 4 步 | 是 | 流程图 |
| 有状态、分支、回退 | 是 | 状态图 |
| 有多个组件互相调用 | 是 | 架构图 |
| 有两种方案对比 | 是 | 对比图 |
| 有错误排查路径 | 是 | 诊断路径图 |
| 单个术语定义 | 通常否 | 无 |
| 短命令或简单表格 | 通常否 | 无 |

## 2. 图示研发步骤

1. 写清教学目的：学生看完图要能判断、解释或操作什么。
2. 选择图示类型：流程图、架构图、状态图、对比图、概念图、实验步骤图。
3. 先写文字草图：节点、箭头、输入输出、边界。
4. 生成图片 prompt。
5. 使用 `imagegen` 生成图片资产，并保存为 PNG/JPG/WebP。课程封面、课程插图、用户明确要求 image-gen 时，必须走这一步。
6. 在学习文件中放图片并写 alt 文本。
7. 检查图中文字是否少、清楚、无幻觉、无错误术语。

Mermaid/SVG 只能用于用户明确允许的确定性工程图，或作为开发草图；不能在用户要求 image-gen、课程封面、课程插图时替代最终图片资产。

## 3. 图片 prompt 模板

```text
为中文 AI Agent 实践课程生成一张教学图。
图示类型：{流程图/架构图/状态图/对比图/诊断路径图}
教学目的：帮助本科/专科学生理解 {知识点/流程/组件关系}。
画面内容：
- 节点 1：{名称与一句短说明}
- 节点 2：{名称与一句短说明}
- 箭头或关系：{关系}
- 边界/人工确认/失败路径：{如有}
风格要求：
- 清晰、简洁、教育类信息图，不要海报感。
- 白色或浅色背景，深色文字，高对比度。
- 中文标签要短，每个节点不超过 12 个字。
- 不要装饰性背景、不要复杂插画、不要无关人物。
输出用途：Markdown 课程页面配图，16:9 或 4:3，最终保存为 PNG/JPG/WebP 位图。
```

## 5. 学生页插入格式

```markdown
![图示：学习卡片助手从输入主题到测试报告的流程](../../assets/lesson-01/card-assistant-flow.png)
```

图片下方必须配一句解释：

```markdown
这张图显示本章 4 个任务的关系：先让 AI 稳定回答，再固定栏目，再加入资料来源，最后用测试主题检查。
```

## 6. 不合格图示

- 只有装饰，没有教学信息。
- 节点太多，一屏看不清。
- 中文标签过长。
- 图中出现课程没有讲过的框架或 API。
- 图里流程和正文不一致。
- 没有 alt 文本。
- 用户要求 image-gen 时却用 SVG/Mermaid 顶替最终图片。
