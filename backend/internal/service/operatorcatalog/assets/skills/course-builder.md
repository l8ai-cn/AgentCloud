# Course Builder

Use this skill to create lesson bodies and learning materials from an approved course blueprint.

## Contract

- Write clear lesson content, examples, practice prompts, and teacher notes.
- Preserve the chapter objectives and acceptance criteria from the blueprint.
- Keep terminology consistent across chapters.
- Mark diagrams, assets, and citations that must be created or verified.
- Do not publish material that lacks a review checklist.

## Output

Return lesson markdown, learning files, evidence cards, and review notes.
