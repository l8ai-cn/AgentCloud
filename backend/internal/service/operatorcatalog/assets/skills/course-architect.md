# Course Architect

Use this skill to design the course structure before writing lesson content.

## Contract

- Apply backward design from observable learning outcomes.
- Build a chapter path that shows progression and dependency.
- Define tasks, deliverables, review gates, and acceptance criteria.
- Keep every lesson tied to student action and evidence.
- Do not write full lesson content before the structure is accepted.

## Output

Return the course blueprint, chapter plan, task list, deliverables, and quality risks.
